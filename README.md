# AI-Based-Meeting-Notes-Generator
The AI-based meeting notes generator turns meeting audio, video or transcripts into structured notes - a summary as well as speaker-attributed action items, decisions and deadlines.

Built as a final project for a graduate AI course at Northeastern University (2026) by [Siddhi Kakani](https://github.com/siddhi1703) and [Simona Matiukaite](https://github.com/SimonaMati).
